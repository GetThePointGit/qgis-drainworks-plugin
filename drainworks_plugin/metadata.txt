Pick a trajectory through the network and inspect the longitudinal profile (BOB, water level, maaiveld) in an embedded side-view.

changelog=
    1.0.5
    - Marked as non-experimental (experimental=False).
    - Fix: hand-edited BOBs now reach the side-view immediately after saving layer edits or re-enriching; previously the old values were drawn until the GeoPackage was reopened.
    - Fix: bob_avg and slope are recomputed from the current bob1/bob2 during enrich, so the thematic map styling follows manual BOB corrections.
    - New: validation warning "BOB op of boven maaiveld" flags placeholder BOBs (RIBX exports sometimes write 0.00 for unmeasured BOBs); such pipes get valid=0 with a clear issue text.
    - Manual: explains the valid field (1 = OK, 0 = issue), placeholder BOBs (0.00) and how to correct them.
    1.0.4
    - Styling line widths are now in screen pixels instead of millimetres (pipes, segments, manholes), so width differences (e.g. pipes coloured/sized by diameter) stay visible and keep a constant on-screen thickness at any map scale.
    - Raised the minimum QGIS version to 3.40 LTR (tested on 3.44); the previous 3.22 was an unverified scaffold default.
    - Housekeeping: the bundled pyqtgraph now ships its MIT LICENSE file.
    1.0.3
    - Fix: enrich and lost storage (steps 2 and 3) wrote the GeoPackage in the background task; like the import they now write on the main thread (in batches), preventing the Windows crash on large datasets.
    - Fix: while choosing a trajectory, no water is drawn on the not-yet-committed (live) segment any more.
    1.0.2
    - Fix: importing a large RIBX crashed on Windows while finalising the GeoPackage; the GeoPackage is now written on the main thread (and committed in batches, faster everywhere).
    - New: a loading bar when opening a GeoPackage.
    1.0.0
    - First public release: three-step pipeline (import / enrich / lost storage), trajectory tool with live side-view, segment styling, GeoPackage metadata with up-to-date detection.
